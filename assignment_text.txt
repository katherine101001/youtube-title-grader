A. Introduction/ Situation/ Background Information 
This assignment requires students to design and implement an autonomous agentic AI tool using 
n8n, an open-source workflow automation platform. The tool must address a real-world data 
mining problem or deploy a trained machine learning (ML) or deep learning (DL) model for 
prediction. Students are expected to demonstrate their understanding of agentic AI concepts, data 
mining techniques, and ML/DL model integration by building a fully functional, end-to-end 
automated workflow in n8n that can perceive, reason, act, and deliver results with minimal human 
intervention. 
 
B. Course Learning Outcomes (CLO) covered 
At the end of this assessment, students are able to: 
CLO 1 
Describe the concept and principles of data mining and its algorithms. 
CLO 2 
Apply the knowledge to design a data mining algorithm. 
CLO 3 
Assess the performance of data mining algorithms for a given problem. 
CLO 4 
Build programming solutions using data mining techniques for a given problem.

F. Task(s) 
In this assignment, you are required to design and implement an autonomous agentic AI solution 
that addresses a real-world problem using data mining and machine learning techniques. The 
solution should not only analyse data and generate predictions but also demonstrate how intelligent 
agents can automate decision-making and actions through workflow orchestration. 
You may choose any application domain, such as retail, healthcare, education, finance, logistics, 
marketing, or human resources. The selected problem should have practical value and be supported 
by a publicly available dataset. Throughout this assignment, you are expected to apply the 
knowledge and skills acquired in this course, including data preparation, exploratory data analysis, 
data mining, predictive modelling, and intelligent workflow automation. 
The final solution should consist of a trained machine learning or deep learning model integrated 
into an n8n workflow that can automatically ingest data, generate predictions, reason over the 
results, and perform appropriate actions or recommendations with minimal human intervention. 
 
Task 1: Project Design and Report (40 Marks) 
Prepare a report describing the design, implementation, and evaluation of your project. The report 
should clearly demonstrate how data mining, machine learning, and agentic AI concepts are 
applied to solve a real-world problem. 
The report should begin by introducing the selected problem and dataset. You should explain the 
business or practical value of the problem being addressed and justify why the chosen dataset is 
suitable. The proposed solution architecture should then be presented in a clear diagram illustrating 
how data flows through the system, from ingestion and processing to prediction, reasoning, and 
output generation. 
Your architecture diagram should include the following layers: 
• 
Trigger Layer 
• 
Data Ingestion Layer 
• 
Prediction Layer 
• 
AI Agent Layer

Task 2b: Exploratory Data Analysis (15 Marks) 
Perform exploratory data analysis and apply appropriate data mining techniques to gain insights 
into the selected problem. You should use suitable visualizations and analytical methods to 
uncover meaningful patterns, trends, relationships, or segments within the dataset. 
This section should cover: 
• 
Appropriate visualizations. 
• 
Application of relevant data mining techniques. 
• 
Interpretation of findings. 
• 
Discussion of business or practical insights. 
 
Task 2c: Predictive Model Development (15 Marks) 
Develop and evaluate a predictive model that addresses the chosen problem. You should select an 
appropriate machine learning or deep learning algorithm, justify your choice, train the model, and 
evaluate its performance using suitable metrics. 
This section should cover: 
• 
Model training process. 
• 
Evaluation metrics and results. 
• 
Interpretation of model performance. 
 
Task 2d: Model Deployment and Integration (10 Marks) 
Prepare the trained model for integration with external systems. You may deploy the model as an 
API, host it on a cloud platform, or implement another suitable approach that allows predictions 
to be accessed programmatically. Suitable technologies include FastAPI, Flask, Koyeb, Render, 
Railway, or other equivalent solutions. 
This section should cover: 
• 
Description of the deployment approach. 
• 
Sample API endpoints.

Task 2e: Agentic AI Workflow Implementation (10 Marks) 
Develop an end-to-end agentic AI workflow using n8n that automates the entire process from data 
ingestion through prediction to action. The workflow should demonstrate how AI agents can 
reason over prediction results and perform meaningful automated actions. 
The workflow should include: 
• 
At least one trigger node. 
• 
Integration with the deployed predictive model. 
• 
At least one AI Agent node. 
• 
At least one automated output or notification action. 
• 
Successful execution of the complete workflow. 
You may use any suitable trigger, AI model, output channel, or automation mechanism, provided 
the workflow demonstrates autonomous reasoning and action based on the prediction results.
